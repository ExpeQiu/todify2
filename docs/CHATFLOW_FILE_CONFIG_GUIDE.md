# Dify Chatflow 文件配置指南

## 🔍 问题诊断

根据测试结果：
- ✅ 文件上传成功
- ✅ 文件 ID 传递成功
- ❌ AI 回复说无法查看文件
- ❌ `retriever_resources: []` - 文件未被检索
- ❌ `total_tokens: 0` - 可能未真正处理

**结论**: 问题在 **Chatflow 配置**，不在文件传递流程。

## 📋 Chatflow 配置检查清单

### 1. 检查输入节点配置

在 Dify 后台，进入 Chatflow 编辑页面：

1. **找到输入节点（Input Node）**
2. **检查是否有文件输入字段**
   - 字段类型应该是 `file` 或 `file-list`
   - 字段名可能是：`files`、`file_list`、`attachments`、`file_ids` 等
3. **确认字段已启用**
   - 字段应该是必填或可选，但不能被禁用

### 2. 检查 LLM 节点提示词

1. **找到 LLM 节点（LLM Node）**
2. **查看提示词（Prompt）**
3. **确认提示词中引用了文件**

**正确的提示词示例**:
```
请分析用户上传的文件内容。

文件信息：{{#files#}}

请根据文件内容回答用户的问题：{{query}}
```

或者：
```
用户上传了以下文件：
{{file_list}}

请分析这些文件的内容，并回答用户的问题：{{query}}
```

**错误的提示词示例**:
```
请回答用户的问题：{{query}}
```
（没有引用文件）

### 3. 检查文件处理节点

某些 Chatflow 可能需要：
1. **文件读取节点（File Reader Node）**
   - 用于读取文件内容
   - 需要配置为读取 `files` 字段

2. **知识库检索节点（Knowledge Retrieval Node）**
   - 如果使用知识库，需要配置检索文件

## 🔧 解决方案

### 方案 1: 在 inputs 中传递文件

如果 Chatflow 的文件输入字段名不是 `files`，需要在 `inputs` 中传递：

**在测试页面中**:
1. 填写"文件输入字段名"（例如：`file_list`）
2. 重新测试

**在后端代码中**:
```typescript
// 如果 Chatflow 的文件输入字段名是 file_list
requestBody.inputs['file_list'] = uploadedFileIds;
```

### 方案 2: 修改 Chatflow 配置

1. **添加文件输入字段**:
   - 在输入节点中添加文件输入字段
   - 字段名设置为 `files`
   - 字段类型设置为 `file-list`

2. **修改提示词**:
   ```
   请分析用户上传的文件内容。
   
   文件：{{#files#}}
   
   用户问题：{{query}}
   
   请根据文件内容回答用户的问题。
   ```

3. **添加文件处理节点**（如果需要）:
   - 添加文件读取节点
   - 连接文件输入到文件读取节点
   - 将文件内容传递给 LLM 节点

### 方案 3: 使用知识库

如果 Chatflow 使用知识库：

1. **上传文件到知识库**:
   - 在 Dify 后台上传文件到知识库
   - 获取知识库 ID

2. **配置知识库检索**:
   - 在 Chatflow 中添加知识库检索节点
   - 配置检索知识库

3. **在提示词中引用检索结果**:
   ```
   根据以下知识库内容回答用户问题：
   
   {{#knowledge#}}
   
   用户问题：{{query}}
   ```

## 💡 常见问题

### Q1: 文件输入字段名是什么？

**A**: 在 Dify 后台的 Chatflow 编辑页面中查看输入节点，找到文件输入字段的名称。

### Q2: 提示词中如何引用文件？

**A**: 使用变量引用，例如：
- `{{#files#}}` - 引用 files 字段
- `{{file_list}}` - 引用 file_list 字段
- `{{#file_list#}}` - 引用 file_list 字段（带格式）

### Q3: 为什么 retriever_resources 为空？

**A**: 可能原因：
1. Chatflow 没有配置文件检索
2. 文件输入字段未启用
3. 文件输入字段名不匹配
4. 提示词未引用文件

### Q4: 为什么 total_tokens 为 0？

**A**: 可能原因：
1. 请求未真正处理
2. 使用了缓存
3. 请求格式不正确

## 📝 配置示例

### 正确的 Chatflow 配置示例

**输入节点**:
- 字段1: `query` (text) - 用户问题
- 字段2: `files` (file-list) - 文件列表 ✅

**LLM 节点提示词**:
```
你是一个专业的文档分析助手。

用户上传了以下文件：
{{#files#}}

用户问题：{{query}}

请根据文件内容详细回答用户的问题。如果文件内容与问题相关，请引用文件中的具体信息。
```

这样的配置应该能够正确处理文件。
