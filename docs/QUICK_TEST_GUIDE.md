# 🚀 Dify 文件上传快速测试指南

## 快速开始

### 1. 启动前端服务

```bash
cd frontend
npm run dev
```

前端服务会在 `http://localhost:3001` 启动

### 2. 访问测试页面

在浏览器中打开：
```
http://localhost:3001/dify-test.html
```

### 3. 配置 Dify API

在页面顶部填写：
- **Dify API Base URL**: `http://47.113.225.93:9999/v1`
- **API Key**: 您的 Dify API Key（从 Dify 后台获取）
- **App ID**: `2c112aca-151b-418d-9c93-8c07160829e9`

### 4. 测试步骤

1. **选择文件**
   - 点击"选择文件"按钮
   - 选择一个 PDF 文件（例如：`【final】2025上海车展一页纸核心信息.pdf`）

2. **发送消息**
   - 在消息输入框中输入：`请分析这个文件的内容`
   - 点击"发送消息"按钮

3. **观察日志**
   - 查看页面底部的"操作日志"区域
   - 应该看到：
     - ✅ `开始上传文件: xxx.pdf`
     - ✅ `文件上传成功: xxx.pdf -> file-xxx`（包含文件 ID）
     - ✅ `发送消息，包含 1 个文件 ID: file-xxx`
     - ✅ `收到响应`（包含 AI 回复）

4. **验证结果**
   - 检查 AI 回复是否引用了文件内容
   - 检查对话记录中是否显示文件 ID

## ❌ 常见问题

### 问题 1: 文件上传失败

**错误信息**: `上传失败: 401` 或 `上传失败: 403`

**解决方法**:
- 检查 API Key 是否正确
- 确认 API Key 有文件上传权限

### 问题 2: 消息发送失败

**错误信息**: `请求失败: 400` 或 `请求失败: 404`

**解决方法**:
- 检查 App ID 是否正确
- 检查 Dify API Base URL 是否正确

### 问题 3: AI 回复未引用文件

**可能原因**:
- Chatflow 配置问题
- 文件输入字段未启用

**解决方法**:
- 在 Dify 后台检查 Chatflow 配置
- 确认文件输入字段已启用
