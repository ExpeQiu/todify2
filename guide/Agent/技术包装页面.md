### 1. 核心设计理念 (Core Design Philosophy)

*   **Chat First (对话优先)**: 用户主要与“主控 Agent”对话，就像在跟一位资深营销总监开会。

*   **Human-in-the-Loop (人机协作)**: 用户可以随时打断 Agent，或者直接在右侧面板修改专家的输出，然后再让主 Agent 继续。

### 2. 页面布局设计 (UI/UX Layout)

#### 右侧：专家工作台 / 交付物预览 (Expert Workspace)
*   **动态面板**: 根据当前调用的工具自动切换内容。

    *   **State D: 物料预览 (Preview)**: 展示《内容总导演》生成的脚本、大纲，支持 Markdown 编辑。

### 3. 系统交互流程 (System Interaction Flow)

**场景**: 用户输入 "帮我包装一下我们的 800V 高压平台技术"。

1.  **Intent Analysis (左侧)**:
    *   主 Agent: "收到。800V 是个好技术，但也很卷。我们需要先确认咱们的技术底座。我先请**技术专家**梳理一下核心参数。"
    *   *(界面显示: 正在调用 `Consult_Tech_Fundamentalist`...)*

2.  **Tool Execution (右侧自动展开)**:
    *   右侧面板切换为 **Tech View**。
    *   流式输出: 核心参数表 (电压、电流、碳化硅模块...)、对比竞品数据。
    *   **User Action**: 用户发现参数有误，直接在右侧修改了“峰值电流”数据。

3.  **Context Sync (同步回左侧)**:
    *   主 Agent 感知到用户修改了数据。
    *   主 Agent: "明白了，峰值电流是 600A。那这个充电速度很快。接下来我们看看**场景**。用户最痛的场景是什么？"
    *   *(界面显示: 正在调用 `Consult_Scenario_Alchemist`...)*

4.  **Scenario Generation (右侧切换)**:
    *   右侧面板切换为 **Scenario View**。
    *   展示卡片: "高速服务区抢桩"、"冬天续航打折"、"急事出门发现没电"。

5.  **Final Output (交付)**:
    *   主 Agent 综合所有信息，在右侧生成最终的《短视频分镜脚本》。
