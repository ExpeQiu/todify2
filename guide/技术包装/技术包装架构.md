### 4. 信息传递流程

#### 4.1 主对话消息流（SendMessage）

```
用户输入 → BaseAISearchPage.handleMessageSent()
         → aiSearchService.sendMessage()
         → SendMessageUseCase.execute()
         → resolveWorkflowId('tech-package')  // 获取 AI 角色 ID
         → agentWorkflowService.executeRole('independent-page-tech-package')
         → DifyGateway.executeChat()  // 调用 Dify API
         → 返回 AI 回复 + conversation_id
```

#### 4.2 工具箱触发流（TriggerAgent）

```
点击工具按钮 → StudioSidebar.onTriggerFeature()
            → BaseAISearchPage.handleTriggerFeature()
            → aiSearchService.triggerFeatureAgent()
            → TriggerAgentUseCase.execute()
            → 根据 featureType 查找 agentId
            → agentWorkflowService.executeRole(agentId)
            → AgentOrchestrator.executeAgent()  // 或 DifyGateway
            → 返回分析结果
```

#### 4.3 SSE 事件流（工具调用实时反馈）

```
前端建立 SSE 连接 → /api/v1/ai-search/tool-events/:conversationId
后端执行工具时   → ToolExecutor.executeTool()
                → toolCallEventManager.emitToolStart()
                → toolCallEventManager.emitToolProgress()
                → toolCallEventManager.emitToolComplete()
前端接收事件     → BaseAISearchPage (useEffect 监听)
                → 更新 activeToolCall / toolCallOutput 状态
                → StudioSidebar 实时显示工具执行状态
```

### 5. 发现的问题及建议

#### 5.1 ⚠️ 专家工具调用链不完整

**问题**：`ToolExecutor.executeAgent()` 中的专家工具调用逻辑有待完善：
- `Consult_Tech` 工具会查找 `tech-fundamentalist` 角色，但该角色配置的是 `direct-agent` 类型
- 当前代码根据工具名称判断是否使用 Dify，但实际数据库配置全部是 Direct Agent

**建议**：统一专家角色的调用方式，建议全部使用 Direct Agent，因为它们已有完整的 prompt 配置。

```typescript:backend/src/services/agent/ToolExecutor.ts
// 当前逻辑（第 486-498 行）需要确保 useDify 逻辑正确
if (toolConfig.name === 'Consult_Tech') {
  targetAgentId = roleId || implementation?.agentId;
  useDify = false; // Consult_Tech 应该使用 Direct Agent
}
```

#### 5.2 ✅ SSE 事件系统已完整实现

- `ToolCallEventManager` 单例模式管理事件订阅
- 前端通过 `EventSource` 接收实时事件
- 支持 tool_start、tool_progress、tool_complete、tool_error 四种事件类型

#### 5.3 ⚠️ 主控 Agent 未配置专家工具

**问题**：`independent-page-tech-package` 角色是 Dify 类型，没有配置 `agentConfig.tools`，因此**不会主动调用专家工具**。

**建议**：如果需要主控 Agent 自动调用专家工具，有两种方案：
1. **方案 A**：将主控 Agent 改为 Direct Agent 类型，并配置 `expertTools` 作为可用工具
2. **方案 B**：保持 Dify 类型，在 Dify 端配置 Function Calling

#### 5.4 ✅ 字段映射配置系统完整

- `StudioSidebar` 包含字段映射配置弹窗
- 支持将功能模块关联到专家角色
- 配置保存到 `independent-page-tech-package` 工作流
